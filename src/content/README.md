# Conteúdo editorial

As próximas etapas poderão mover cartas, memórias e registros para arquivos Markdown com metadados.

Diretrizes:
- Use slugs curtos, sem acentos e em kebab-case.
- Mantenha datas no formato ISO `YYYY-MM-DD`.
- Não invente datas ou acontecimentos.
- Não inclua dados de contato, endereços ou outras informações sensíveis.
- Use apenas fotografias com autorização para publicação.
- Mantenha textos pessoais em português do Brasil.
